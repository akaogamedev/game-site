# ツッコミ道場のサイト追加

unityroomの公開後、100本投稿企画の16本目として既存サイトへ追加。

- 公開ページ `https://unityroom.com/games/tsukkomi-dojo` をログアウト状態で取得し、公開済み・投稿日2026-09-26を確認。
- 紹介内容はゲーム側の `Docs/game-spec.md`・`Docs/unityroom-release.md`・`Assets/Game/Resources/Neta/neta01.json`・`ScoreCalculator.cs`（称号）を参照。
- 日本語・英語のMarkdownと、簡体字・繁体字・韓国語・スペイン語・フランス語・ドイツ語・ブラジルポルトガル語の翻訳を追加。
- カバーはunityroom用に承認済みのアイコン `icon-512.png`。
- 動画はX投稿用の `tsukkomi-dojo-x-mixed.mp4` の19.3秒から15秒（ボケ1「おひとりで食べるんですか？」→ツッコミ→ドッ！！→ボケ2の振り→2回目のドッ）を960×540・音声付きで切り出し。ポスターはボケ1のドッ！！の場面。

## 検証

- `npm run build` 成功、211ページ生成。9言語の詳細ページとトップの16/100を確認。
- ローカルブラウザの日本語1280px・390px、英語390pxで横はみ出しなし。動画15秒・初期ミュート・再生進行、video.errorなし。
- 掛け合いの自動再生はブラウザペインで開始待ちのまま止まるが、既存のバチッとポーズ！でも同じでペイン側のアニメーション抑制によるもの。

掛け合いはユーザーの指示で4・5行目を修正（会場の盛り上がりはAIが判定する、おナガは自信を見せて締める）。mainへPushしてCloudflare Pagesで公開。
